# 写作要求蒸馏来源

本技能从作者维护的文献综述与数学建模写作规则，以及真实写作返工反馈中整理而来。保留的核心是研究者的判断与解释、一条贯通的主线，以及由案例驱动的诊断和修订。

- 文献综述写作：围绕问题比较研究，区分结果与解释，不用摘要串联代替综合。
- 数学建模写作：说明方法作用及选择理由，用真实结果解释取舍，使图文承担论证。
- 写作返工反馈：保留批评原话与适用条件，区分已知问题、尚未解决的问题及明确认可的改稿。

公开版本只含独立整理的规则与精选反馈，不附其他技能的完整文件、原始研究稿件、截图或完整对话。精选反馈的节选状态在案例中标明。案例中的建议方向不等于经过用户验收；B007、B008仍是重要但未解决示例。
