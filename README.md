# xxnature
**由于codex写作实在是太胆小所以做了这个，如果codex生成的文件不满意你也可以直接发给别的AI“我觉得他表述上写的太让人难看懂了，为什么”，再把意见返修**

以一条贯通的主线组织写作，呈现研究者的思考感与自然论证。

让读者看清为什么选择、结果意味着什么、下一步据此怎么做。面向科研论文、研究方案、文献综述和竞赛文章，重视作者的解释责任与成品的实际用途。

## 工作方式

写作从读者、目标和材料开始，复杂文稿先组织主线。结果不能只列数据，正式方案也不能变成聊天讲义。

当用户说“这里不对”或“整篇感觉不对”时，技能先判断可能的问题，查找类似案例，展示历史反馈原话、匹配理由和结果状态，等待用户确认方向后再改。具体修改指令直接执行。完整提示词按需生成。

返工记录先进入待验证；用户明确认可对应版本后才收入成长库。确认修改方向不等于认可改稿。

## 安装与使用

从 [Releases](https://github.com/OVERTIMEyu/xxnature/releases) 下载ZIP，将其中的`xxnature`文件夹放入自己的技能目录；文件夹内应直接包含`SKILL.md`。Codex的个人技能通常位于`~/.codex/skills/`。

也可以克隆仓库到该目录，或让技能安装器从`OVERTIMEyu/xxnature`的仓库根目录安装。已有安装时，先保留自己的实例库再合并更新，避免发行版的空库替换个人记录。

使用示例：

> 使用 $xxnature 帮我组织这篇文章，先给出贯通全文的思路。

> 使用 $xxnature。我觉得这一段不对，先判断是什么问题，找出以前相关的反馈让我确认。

启用本技能时，按技能约定在本地保留返工记录；明确满意后收录成长实例。如某次材料不应保存，请直接说明。记录工具不联网，写作时也不会自动提交Git或上传案例。

## 案例如何区分

| 位置 | 作用 |
| --- | --- |
| 基础实例库 | 6项已知写作问题及精选用户反馈，不等于成功改稿 |
| 重要但未解决示例 | B007、B008，来自同一条未成功返工链，单独查阅 |
| 待验证 | 安装后的实际返工记录，等待用户评价 |
| 成长实例库 | 用户明确认可的具体改稿及适用条件 |

查看[错误与提示词实例索引](实例库/索引-错误与提示词-v1.md)。公开版不包含私人项目文件、原始截图、完整对话或个人成长记录。

## 管理工具

技能文本可直接阅读；实例管理脚本需要Python 3.9或以上，仅使用标准库。

```text
python scripts/管理-实例库-v1.py list --query 主线
python scripts/管理-实例库-v1.py list --unresolved
python scripts/管理-实例库-v1.py list --pending
python scripts/管理-实例库-v1.py check
python -m unittest discover -s tests -v
```

记录字段、认可条件和管理命令见[成长规则](references/规则-实例收录与成长-v1.md)。自动调用取决于宿主加载情况，明确指定`$xxnature`可以请求该流程。它积累可回查的写作案例，不训练模型，也不在后台监听其他对话。

xxnature与Nature期刊无隶属关系。
